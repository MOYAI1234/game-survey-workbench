# Insight Synthesis Prompt

Write Markdown insight synthesis for a game survey analysis workflow.

## Input

- Research goal
- Statistical findings
- Coded open-text themes
- Retrieved knowledge snippets

## Task

- Produce a concise narrative insight section grounded in the supplied evidence.
- Connect statistical findings, coded themes, and knowledge where appropriate.
- Use inline citations or explicit evidence references in the narrative.

## Constraints

- Every claim must point back to a stat finding, coded theme, or knowledge source.
- Do not fabricate evidence.
- Keep the output in Markdown prose suitable for a report section.
