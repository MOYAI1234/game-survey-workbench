# Active Plans

`docs/plans/` now stores active and future-facing planning documents only.

Rules for this directory:

- Do not leave completed `1.0` or `2.0` history here.
- Move historical planning artifacts into `docs/archive/plans/`.
- Start new product iteration plans at `2.1`, then continue with `2.2`, `2.3`, and so on.

Use these locations:

- Active planning: `docs/plans/`
- Historical archive: `docs/archive/plans/`
- Long-lived roadmap: `docs/product-roadmap.md`
